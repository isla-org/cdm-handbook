# Legacy Format JSON Examples

From CDM Version 7 onwards, the default Serialization format for Rune has changed. The original format, now termed the "legacy" format, has been replaced with a new "Rune" format.

The example JSON in this folder was built when CDM Version 7 was still in development and used the legacy format. These examples are still useful for reference as firms migrate from the legacy format to the new Rune format.
